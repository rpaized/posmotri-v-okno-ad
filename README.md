Посмотри в окно
Учебный проект Яндекс Практикума. На сайте можно смотреть видео из окон в разных городах и искать их по городу и времени суток.

Ссылка на репозиторий: https://github.com/rpaized/posmotri-v-okno-ad

Чтобы открыть сайт, откройте файл index.html в браузере. Нужен интернет, потому что видео загружаются с сервера.
